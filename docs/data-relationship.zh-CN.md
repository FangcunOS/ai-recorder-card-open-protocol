# 录音卡、手机与电脑的数据关系

[English](./data-relationship.md)

动手写小程序、App 或电脑端之前，先按本文对齐数据放在哪。本文描述 AI录音卡、录音卡、手机缓存和电脑档案之间的关系。帧格式见 [中文协议](./protocol.zh-CN.md) 与 [Protocol](./protocol.md)。连上录音卡的步骤见 [接入技能](./skill.zh-CN.md)。

手机用微信小程序还是独立 App，下面的关系相同。差别只在缓存容量和后台传输能力。

## 三端各是什么

| 端 | 角色 |
| --- | --- |
| 录音卡 | 采集源。保存卡内录音和文件列表 |
| 手机 | 缓存。保存尚未交给电脑的音频，以及列表元数据 |
| 电脑 | 档案。保存完整音频、语料正文、转写和可检索详情 |

```text
录音卡  --BLE 协议-->  手机缓存  --应用同步-->  电脑档案
   |                                      ^
   +------------ BLE 协议（网页测试平台）--+
```

两条链路互相独立：

- **卡 ↔ 手机、卡 ↔ 电脑**走公开 BLE 协议。电脑今天用 Web Bluetooth 测试平台直接读卡。
- **手机 ↔ 电脑**走应用自己的同步会话，不是录音卡协议帧。

手机可以只连着卡，也可以只连着电脑。

## 各端保存什么

| 数据 | 录音卡 | 手机 | 电脑 |
| --- | --- | --- | --- |
| 音频文件 | 卡内原始录音 | 待回传的源文件，或尚未清掉的缓存 | 完整音频，权威副本 |
| 列表 | 文件名、时间、大小 | 标题、时间、客户、同步状态 | 可检索的完整条目 |
| 语料正文 / 转写 | 不保存 | 不常驻；连上电脑后按需拉取 | 权威副本 |
| 客户、标题、同步状态 | 不保存 | 列表元数据 | 与音频、语料放在一起 |

同一条录音用卡上的文件名对齐。用户修改的标题只存在于手机和电脑，不能拿标题回卡上查找。

## 电脑档案目录

电脑上的权威副本放在仓库里的 `archive/`。音频和语料分开放，用卡上文件名的主名对齐。

| 数据 | 目录 | 例子 |
| --- | --- | --- |
| 电脑音频 | `archive/audio/` | `archive/audio/note20260710-162938.wav` |
| 电脑语料 | `archive/corpus/` | `archive/corpus/note20260710-162938.md` |

这两个目录只留在本机。录音和语料不提交。目录里的 `.gitkeep` 用来保住空目录。对话接入时用 `tools/qs668-bringup.py` 把导入结果直接写进 `archive/audio/`。云转写用 `tools/qs668-transcribe.py`，配置见仓库根目录 `.env.example`，结果写入 `archive/corpus/`。

## 一份录音落在哪

| 阶段 | 卡内文件 | 手机音频 | 手机列表 | 电脑音频 | 电脑语料 |
| --- | --- | --- | --- | --- | --- |
| 只在卡上 | 有 | 无 | 无 | 无 | 无 |
| 待回传 PC | 有 | 有 | 待回传 | 无 | 无 |
| 同步中 / 失败 | 有 | 有 | 同步中或失败 | 不完整 | 无 |
| 已同步，缓存还在 | 有 | 有 | 已同步 | 完整 | 有则在电脑 |
| 已同步，手机源文件已删 | 有 | 无 | 仅元数据 | 完整 | 有则在电脑 |
| 电脑直接从卡导入 | 有 | 无 | 无 | 完整 | 有则在电脑 |

实时音频还没保存成文件时，不进入上表。等它成为卡上或手机上的一条文件，再标「待回传 PC」。

同步成功并经电脑确认音频完整之后，手机默认删除本地源文件，列表保留标题、时间、客户和已同步状态。卡内录音仍保留。删除卡内文件是另一次明确操作，不并进默认同步。

## 手机列表状态

列表只使用下面四档，避免把“本地文件已删”和“同步失败”显示成同一种。

| 状态 | 手机上有什么 | 点进详情 |
| --- | --- | --- |
| 待回传 PC | 源文件 | 可播放，看本地预览 |
| 已同步，缓存还在 | 源文件和元数据 | 未连电脑也可播放缓存；完整语料要连上电脑再拉 |
| 已同步，仅元数据 | 标题、时间、客户、同步状态 | 未连电脑时显示「请连接电脑查看」；已连则按需拉取正文和转写，不常驻手机 |
| 同步中 / 失败 | 源文件还在 | 显示进度或重试，不显示成已删除 |

## 动手时的边界

- 组帧、文件导入和录音控制以协议文档为准。
- 客户、标题、同步状态、语料正文由手机和电脑的应用数据保存，不写回录音卡。
- 小程序和 App 共用这一套状态，不各写一套生命周期。
